# Flores Amarillas para Ti — Plantilla gratuita de unDetalleDev

Un pequeño ramo digital para regalar. Gratis, sin instalaciones y sin conexión.

## Abrir

Extrae el ZIP completo y haz doble clic en **index.html**. Pulsa «Recibir mis flores» y espera a que florezca el ramo. Toca una flor para acariciarla. También puedes usar Tab y Enter o la barra espaciadora.

## Personalizar en cinco minutos

**Edita js/config.js** con el Bloc de notas o tu editor de texto. No necesitas cambiar el HTML, los estilos ni la lógica de la página.

- `recipient`: nombre de quien recibe las flores.
- `intro.text`: frase inicial.
- `intro.buttonText`: texto del botón.
- `message.title`: título de la dedicatoria.
- `message.text`: mensaje (puedes conservar los saltos de línea).
- `message.signature`: firma.
- `interaction.hint`: indicación para tocar las flores.

Por ejemplo, cambia estas líneas conservando las comillas y las comas:

```js
recipient: "Valentina",
```

```js
signature: "Con cariño, Alex 💛"
```
